# BlockForgePlatinum

BlockForgePlatinum: A distributed, real-time data processing engine with auto-scaling capabilities for dynamic data pipeline orchestration.

With BlockForgePlatinum, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockForgePlatinum.git`
2. `cd BlockForgePlatinum`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
